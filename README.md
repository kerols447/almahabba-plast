# المحبة بلاست — دليل التشغيل والنشر

موقع ثابت (HTML + Tailwind CDN + JavaScript أصلي) بدون أي خطوة بناء. كل النصوص العربية/الإنجليزية في ملف واحد، وكل السلوك في ملف واحد.

---

## 1) بنية المشروع

```
index.html  about.html  products.html  custom-colors.html
quality.html  contact.html  privacy.html  terms.html  404.html
assets/
  css/custom.css          → أنماط مخصّصة (أزرار، كروت، هيدر، حقول)
  js/tailwind.config.js   → ألوان وخطوط وبراندز التصميم
  js/main.js              → المحرك: الثوابت + اللغة + الهيدر/الفوتر + النماذج
  js/translations.js      → كل النصوص (عربي + إنجليزي) في مكان واحد
  img/                    → الصور المستخدمة في الموقع
sitemap.xml  robots.txt
```

---

## 2) تعديل النصوص (الأكثر شيوعًا)

كل جملة في الموقع موجودة في `assets/js/translations.js`، مقسّمة لمجموعتين:
- `ar: { ... }` للعربية
- `en: { ... }` للإنجليزية

كل مفتاح له نفس الاسم في المجموعتين. عدّل القيمة بين علامات الاقتباس، وحافظ على الاسم والفاصلة.

مثال — تغيير عنوان الرئيسية:
```js
'hero.title': 'عنوانك الجديد',
```

في ملفات HTML، النص يُستدعى بالمفتاح عبر `data-i18n`:
```html
<h1 data-i18n="hero.title"></h1>
```
لا تكتب النص داخل الـ HTML مباشرة — اتركه فارغًا ودع المفتاح يملؤه، وإلا سيظهر نص ثابت لا يتغيّر مع تبديل اللغة.

> ملاحظة: لا تكتب العربية عبر أدوات الطرفية (curl/bash) لأنها تتحوّل لرمز `؟`. عدّل الملف بمحرر نصوص عادي (VS Code / Notepad++) واحفظه بترميز UTF-8.

## 3) تعديل المنتجات

قائمة المنتجات في شبكة "منتجاتنا" موجودة في `assets/js/main.js` داخل المصفوفة `PRODUCTS`. كل منتج كائن:
```js
{
  category: 'masterbatch',          // masterbatch | pet | raw
  img: 'assets/img/pellets-blue.jpg',
  swatch: '#1F2937',                // لون البطاقة الصغيرة
  name: { ar: 'ماستر باتش أسود', en: 'Black Masterbatch' },
  desc: { ar: 'وصف عربي', en: 'English description' }
}
```
- لإضافة منتج: انسخ كائنًا وغيّر القيم وأضِف فاصلة.
- لتغيير التصنيف: عدّل `category` (يحدّد التبويب الذي يظهر فيه المنتج).
- احذف `[TO CONFIRM]` من الوصف بعد استبدالها بمعلومات فعلية.

## 4) تعديل الألوان والهوية

الألوان الأساسية في `assets/js/tailwind.config.js`:
```js
primary: '#0B3C7A'   // الأزرق الأساسي
navy:    '#071F3F'   // الكحلي (الخلفيات)
accent:  '#FF7A1A'   // البرتقالي (الأزرار)
surface: '#F4F6F9'   // الرمادي الفاتح
ink:     '#1F2937'   // لون النص
```
غيّر القيمة هنا وستتحدّث كل الصفحات تلقائيًا (تُستخدم كأصناف مثل `bg-primary` و`text-accent`).

الأرقام والثوابت في أعلى `main.js`:
```js
const WHATSAPP_NUMBER = '201274889660';   // زر واتساب العائم + كل الروابط
const CONTACT_EMAIL   = 'Nourhamam2014@yahoo.com';
const PHONE_1 = '+201221328445';
const PHONE_2 = '+201274889660';
```
عدّل رقمًا مرة واحدة هنا، وينعكس على الموقع كله.

## 5) استبدال الصور

1. ضع الصورة الجديدة في `assets/img/` باسم دالّ (مثل `pellets-black.jpg`).
2. حدّث المرجع في مكانه:
   - صورة منتج → في مصفوفة `PRODUCTS` داخل `main.js` (حقل `img`).
   - صورة ثابتة في صفحة → ابحث عن اسم الملف في ملف الـ HTML وعدّل `src` و`alt`.
3. حافظ على `loading="lazy"` و`alt` وصيغة `width/height` لتجنّب قفز الصفحة.
4. الأفضل: صور JPG/WebP بعرض ≈1000–1200px ووزن أقل من 300KB.

> الصور الحالية منسدلة من مجلد `elmahaba` وتم اختيار الأنسب منها. أي صورة تحمل علامة `egyplast` أو لقطة شاشة فيسبوك لا تُستخدم.

## 6) ضبط نموذج التواصل (Formspree) — خطوة إلزامية قبل الاستقبال

حاليًا النموذج يعرض رسالة خطأ مقصودة لأن المعرّف غير مضبوط. للتفعيل:
1. أنشئ حسابًا مجانيًا على https://formspree.io وسجّل الدخول.
2. أنشئ Form جديدًا واضبط بريد الاستلام على `Nourhamam2014@yahoo.com`.
3. انسخ معرّف النموذج (يظهر في رابط النموذج مثل `formspree.io/f/abcdxyzw` → المعرّف `abcdxyzw`).
4. في `assets/js/main.js` استبدل السطر:
   ```js
   const FORMSPREE_ENDPOINT = 'https://formspree.io/f/YOUR_FORM_ID';
   ```
   بـ:
   ```js
   const FORMSPREE_ENDPOINT = 'https://formspree.io/f/المعرّف-الخاص-بك';
   ```
5. جرّب إرسال طلب كامل — يجب أن تصلك رسالة نجاح وأن يصل البريد لصندوقك.

## 7) ضبط النطاق (الدومين)

النصوص الحالية تستخدم نطاقًا افتراضيًا `https://www.almahabba-plast.com`. عند شراء الدومين الفعلي، استبدل هذا النطاق في:
- كل ملفات HTML: وسوم `<link rel="canonical">` و`og:url` و`og:image`.
- `sitemap.xml`: كل وسوم `<loc>`.
- `robots.txt`: سطر `Sitemap:`.

(بحث واستبدال بسيط في محرر النصوص يغطّي كل المواقع.)

## 8) النشر (اختَر طريقة واحدة)

الموقع ملفات ثابتة؛ أي استضافة مواقع ساكنة تصلح. الخيارات بالسهولة:

**أ) Netlify (الأسهل — سحب وإفلات)**
1. ادخل https://app.netlify.com/drop
2. اسحب مجلد المشروع كله (بعد استبدال النطاق ومعرّف Formspree) وأفلته.
3. تحصل على رابط فوري؛ ثم اربط دومينك من Site settings → Domain management.

**ب) Cloudflare Pages / Vercel**
اربط المستودع (GitHub) أو ارفع المجلد، وحدّد مجلد الإخراج كجذر المشروع بدون خطوة بناء (Build command: فارغ).

**ج) استضافة cPanel تقليدية (مثل أي شركة استضافة مصرية)**
ارفع كل الملفات عبر مدير الملفات أو FTP إلى مجلد `public_html` مع الحفاظ على مجلد `assets`.

**بعد النشر:**
- افتح الموقع وتأكد أن كل الصفحات تعمل وزر واتساب يفتح محادثة.
- جرّب النموذج من رابط حيّ (وليس من القرص) للتأكد من وصول البريد.
- أرسل `sitemap.xml` في Google Search Console.

## 9) بنود تحتاج تأكيد الشركة (معلّمة [TO CONFIRM] في الملفات)

- العنوان التفصيلي (الشارع + المنطقة الصناعية) لدبوس الخريطة.
- المواصفات/الفئات التفصيلية لكل منتج والحد الأدنى للكمية.
- القطاعات المستهدفة في "لمن نخدم".
- نص كلمة الإدارة المنسوب للأستاذ نور حمام.
- قرار عرض شهادة تقدير المعرض من عدمه.
- رابط صفحة فيسبوك الرسمية (يُضاف للفوتر عند توفّره).

ابحث عن `[TO CONFIRM]` في `translations.js` و`main.js` وملفات HTML لمراجعتها كلها.
